# Blindspot frontend

React + Vite + three.js. Setup and architecture: [project README](../README.md). Folder layout, layering rules, conventions and "how to add a page / route / string": [docs/CODEBASE.md](../docs/CODEBASE.md).

```bash
npm install
npm run dev            # http://localhost:5173 (set VITE_API_BASE_URL in .env to use the backend)
npm run build
npm run screenshots    # Playwright walkthrough -> ../docs/screenshots, fails on console errors
```
